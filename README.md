# 🔐 Spring Boot JWT Authentication System

A secure and scalable backend authentication system built using Spring Boot, JWT, MySQL, Docker, and REST APIs.

 ## Features

  JWT Authentication
  Refresh Token Authentication
  Email Verification
  Forgot Password & Reset Password
  Role-Based Security
  Rate Limiting
  Swagger API Documentation
  Dockerized Deployment
  MySQL Integration
  Global Exception Handling
  Secure Environment Variables


-------------------------------------

## Tech Stack

* Java 17
* Spring Boot
* Spring Security
* JWT
* MySQL
* Docker
* Gradle
* Swagger/OpenAPI

⚙️ Docker Setup

Run Project
docker-compose up --build

Stop Project
docker-compose down
-------------------------------------

## Environment Variables

Create a `.env` file:

MYSQL_ROOT_PASSWORD=password
MAIL_PASSWORD=mail_password
